# Phase 04: UIの整理とブラッシュアップ

新機能追加ではなく、既存UIの見た目と一貫性を整えるフェーズ。ツールバー・ツール設定・カラーピッカー・カーブエディタ・パフォーマンスモニターなど、既存コンポーネントのレイアウト・余白・配色・文言を統一し、使い勝手を底上げする。挙動（ツールの機能・パラメータの意味）は変更しない。

## Tasks

- [ ] 現状のUIを棚卸しする:
  - `index.html`、`src/ui/components/tool-bar.ts`、`src/ui/tool-settings.ts`、`src/ui/color-picker.ts`、`src/ui/curve-editor.ts`、`src/ui/perf-monitor.ts` を確認し、`docs/review/ui-layer.md` に記録されたUI改善候補と合わせて、余白・配置・フォント・配色のばらつきを洗い出す
  - Phase 01 と同様の Electron 起動検証パターン（`scripts/verify-*.mjs` を参考にした playwright-core の `_electron`）でアプリを起動し、変更前のスクリーンショットを `screenshots/ui-polish-before/` に保存する

- [ ] UIの共通スタイル基盤を整える:
  - `index.html` と各UIコンポーネントに散在するハードコードされた色・余白・フォントサイズの値を洗い出し、共有のCSS変数または定数として一箇所にまとめる
  - 既存のスタイル定義（`index.html` 内のスタイルタグや各コンポーネントのスタイル）の記述パターンを踏襲する

- [ ] ツールバー・ツール設定パネルを整理する:
  - `tool-bar.ts`、`tool-settings.ts`、`tool-config.ts` を対象に、ツールとパラメータのグルーピング・レイアウトを分かりやすく整える
  - ツールの機能・パラメータの挙動そのものは変更しない

- [ ] カラーピッカーとカーブエディタのUIを整える:
  - `color-picker.ts`、`curve-editor.ts` のレイアウトの一貫性、ラベルの分かりやすさを改善し、タスク2で整えた共通スタイル基盤に合わせる

- [ ] パフォーマンスモニターなど残りのオーバーレイ/HUD要素のスタイルを整える:
  - `perf-monitor.ts` を対象に、表示位置や視認性を含めて他コンポーネントと統一感のあるスタイルにする

- [ ] 変更後のアプリを起動して確認する:
  - Phase 01 と同じ検証パターンでアプリを起動し、変更前と同じ画面・操作を再現したスクリーンショットを `screenshots/ui-polish-after/` に保存する
  - `screenshots/ui-polish-before/` と見比べてレイアウト・余白の改善を確認し、ツールバー・ツール設定・カラーピッカー・カーブエディタ・パフォーマンスモニターが機能的に問題なく動作すること（クリック・入力に反応すること）を確認する

- [ ] `npm test` と `npm run build` を実行し、UI調整によるリグレッションがないことを最終確認する。
