# Block 6.5: イラストアプリ基礎機能の拡充

## 目的

フィルター・パス（Block 7）の前に、イラストアプリとして日常的に使うために
不可欠な基礎機能を揃える。Block 1〜6 で描画・レイヤー・保存の基盤は完成しているため、
その上に「制作ワークフロー」を成立させる機能を載せる。

## 実装順序（ユーザー指定の優先度ベース）

実装上の依存関係から、**選択範囲→移動→変形** はまとめて1フェーズにする。
それ以外は指定順を尊重する。各機能は独立して着手・コミット可能。

```
Phase A（軽量・即効）  : 1 左右反転 / 2 カーソルプレビュー / 3 ショートカット拡充
Phase B（描画補助）    : 4 塗りつぶし許容値 / 5 背景色 / 6 自動保存
Phase C（ブラシ拡張）  : 7 ぼかし筆 / 8 直線 / 9 手ブレ補正UI / 10 筆圧カーブ編集
Phase D（選択・変形）  : 11 選択範囲 → 13 移動 → 12 変形（依存順に並べ替え）
Phase E（カラー・保護）: 14 カラーパレット / 15 HSV / 16 アルファロック
```

# Phase A: 軽量・即効

## A-1: 左右反転表示

### 目的
キャンバスを左右反転して表示し、デッサンの狂いを客観視する（描画データは変えない）。

### 設計
`Viewport` に `flipX: boolean` を追加。表示変換にのみ反映し、ペン入力の逆変換にも対応する。
回転と同様、`vs_display` の変換にミラーを掛け、`toCanvas` の逆変換でも反転を打ち消す。

### 実装
- `src/viewport.ts`: `flipX` フィールド、`toggleFlip()`、`toCanvas`/`getTransform` に反映
- `shaders/composite.wgsl` `vs_display`: スケール適用前に `c_pos.x *= flip`（flip=±1）
- ViewportUniforms に `flip: f32` を追加（padding 調整）
- `src/main.ts`: ショートカット（例 `H`）でトグル、`updateViewport` に渡す

### 注意
- ペン座標の逆変換に flip を必ず含める（描画位置ズレ防止）
- 反転中はUIに状態表示（任意）

### 完了条件
- [ ] キャンバスが左右反転表示される
- [ ] 反転中もペン入力位置が正確
- [ ] トグルで元に戻る

## A-2: ブラシカーソルプレビュー

### 目的
マウス/ペン位置に現在のブラシ径の円を表示し、サイズ感を可視化する。

### 設計
WebGPU canvas とは別に、HTML overlay（絶対配置の `<div>` か軽量 2D canvas）で
円を描く。スクリーン座標にそのまま追従し、半径は `ブラシ径 × viewport.scale` で換算。

### 実装
- `index.html`: `<div id="brush-cursor">`（border 円・pointer-events:none）
- `src/main.ts`: `pointermove`（描画と別に window で監視）でカーソル div を移動・リサイズ
  - 半径 = `strokeManager.maxSize * viewport.scale / 2`
  - パン中・UI上では非表示
- 回転/反転時も中心位置は追従（円なので形は不変）

### 完了条件
- [ ] ブラシ位置に円が表示される
- [ ] サイズ変更・ズームで円の大きさが追従
- [ ] 描画の邪魔をしない（pointer-events なし）

# Phase B: 描画補助

## B-1: 塗りつぶし許容値（tolerance）

### 目的
バケツ塗りで色差の許容範囲を持たせ、アンチエイリアス境界も塗れるようにする。

### 設計
現在の `isSameColor` は完全一致（tolerance=0）。色差のしきい値を導入する。
committed はプリマルチプライド float16 なので、比較は straight color の距離で行う。

### 実装
- `src/main.ts` `handleBucketFill` / `isSameColor`:
  - `tolerance`（0〜1）を引数に、`abs(c - ref)` の最大チャンネル差 ≤ tolerance で同色判定
  - α も考慮（アンプリマルチプライドして比較、α差も含める）
- UI: バケツ選択時にスライダー表示（許容値 0〜100%）
- 任意: 隙間を埋める「拡張」ピクセル数（後回し可）

### 完了条件
- [ ] 許容値スライダーで塗り広がりが変わる
- [ ] アンチエイリアス境界がきれいに塗れる

---

## B-2: 背景色の選択

### 目的
白背景 / 透明背景を切り替える。書き出しにも反映。

### 設計
「背景レイヤー」を最下層に持つか、合成時の下地色を持つかの2案。
MVP は **合成の下地色**（透明 or 指定色）を持つ方式が軽量。
PNG 書き出し時に「背景込み / 透明」を選べるようにする。

### 実装
- `pipeline.ts`: `backgroundColor: {r,g,b,a} | null`（null=透明）
  - render()/compositeLayers の最初に背景色で塗る（透明なら何もしない）
  - exportToPNG: 背景込みオプション（背景色を合成してから出力）
- UI: 背景色スウォッチ（白/透明/カスタム）
- 画面の「紙」表示（fs_paper）とは別概念：紙は常時表示の台紙、背景はアート下地

### 完了条件
- [ ] 透明 / 白 / 任意色を切替できる
- [ ] PNG 書き出しに背景設定が反映

## B-3: 自動保存

### 目的
クラッシュ対策。一定間隔でプロジェクトを退避し、起動時に復元提案。

### 設計
`savePmx` のバイト列を Electron の userData に書き出す（IPC 経由）か、
ブラウザの IndexedDB に保存。Electron 前提なら fs が確実。

### 実装
- `electron/main.ts` + `preload.cjs`: `autosave:write` / `autosave:read` IPC
- `src/main.ts`: 一定間隔（例 3分）かつ操作後に savePmx → 退避
  - 退避は1〜2世代ローテーション
- 起動時：退避ファイルがあれば「復元しますか？」を提示
- 注意: 大きいキャンバスの readAllLayers は重いので、アイドル時/間隔を空けて実行

### 完了条件
- [ ] 一定間隔で自動退避される
- [ ] 起動時に復元できる

# Phase C: ブラシ拡張

## C-1: ぼかし筆

### 目的
下地の色を混ぜてぼかす専用ツール（色を置かず、既存色を平滑化／引き伸ばす）。

### 設計
既存の「引きずり混色（progressive）」基盤を流用できる。
ぼかし筆 = `wet≈1.0` かつ「ブラシ色を注入しない（deposit=smudge）」モード。
あるいは周辺ピクセルの平均で committed を更新する専用パス。

実装案A（軽量・既存流用）:
- progressive の deposit を `smudge` のみ（wet=1相当）にする「ぼかしツール」を追加
- 色を置かず既存色だけを引き伸ばす

実装案B（本格・GPUぼかし）:
- ブラシ範囲の committed を読み、ガウシアン平均して書き戻す Compute パス

MVP は案A。`currentTool='blur'` を追加し、progressive 経路で deposit=smudge に。

### 実装
- `src/main.ts`: Tool に `'blur'` 追加、UI ボタン/ショートカット
  - blur 時は wet=1・deposit=smudge（ブラシ色を混ぜない）で buildColoredStroke
- スナップショットは pen-down 時の committed（既存の仕組み）

### 完了条件
- [ ] ぼかし筆で境界がなじむ
- [ ] 色を置かず既存色だけを動かす

# Phase D: 選択・移動・変形

依存順: **選択範囲 → 移動 → 変形**（移動/変形は選択範囲を対象に動く）。

## D-1: 選択範囲

### 目的
矩形/投げ縄/自動選択で範囲を作り、以降の描画・塗り・移動・変形を範囲内に限定する。

### 設計
選択範囲を **マスクテクスチャ（r8unorm or rgba16float の α）** で保持。
- 矩形/投げ縄: CPU でパスを作り mask に描く（または GPU でステンシル）
- 自動選択: committed を読み、tolerance で連結領域を mask 化（バケツの連結処理を流用）
描画時は brush の出力に mask を乗算（mask 外は描かれない）。

### 実装
- `src/render/selection.ts`（or pipeline 内）: `selectionMask: GPUTexture`
- brush.wgsl / bake: 選択中は mask を参照して stamp_alpha に乗算
  - もしくは bake パスで mask を乗算（影響範囲が広いので設計注意）
- UI: 選択ツール（矩形/投げ縄/自動）、選択解除、反転
- マーチングアント表示（点線枠）は任意（MVP は半透明オーバーレイでも可）

### 完了条件
- [ ] 矩形/投げ縄/自動で範囲選択できる
- [ ] 範囲外には描画されない
- [ ] 選択解除・全選択

---

## D-2: 移動ツール

### 目的
アクティブレイヤー（または選択範囲）の内容をドラッグで移動する。

### 設計
移動対象（レイヤー or 選択範囲内のピクセル）を一時テクスチャに切り出し、
オフセットを持って合成プレビュー → 確定で committed に書き戻す。
Undo は「移動前スナップショット」を fill レコードで記録。

### 実装
- `pipeline.ts`: `beginMove()`（対象を切り出し）/ `updateMove(dx,dy)` / `commitMove()`
  - 選択範囲があればその範囲、なければレイヤー全体
- `src/main.ts`: 移動ツール、ドラッグでオフセット更新、確定で履歴記録

### 完了条件
- [ ] レイヤー/選択範囲をドラッグで動かせる
- [ ] 確定・Undo できる

## D-3: 変形

### 目的
選択範囲/レイヤーを拡大縮小・回転・自由変形する。

### 設計
対象を一時テクスチャに切り出し、変形行列（scale/rotate/translate、発展で4点ホモグラフィ）
でプレビュー描画。確定で committed に焼き込む。ハンドルUIで操作。

### 実装
- `src/render/transform.ts`: 変形行列でテクスチャを描く専用パス（双線形補間）
- ハンドル（8点 + 回転）の overlay UI、ドラッグで行列更新
- 確定: 変形結果を committed に書き戻し、Undo 用スナップショット記録
- MVP: 拡大縮小＋回転（自由変形=ホモグラフィは発展）

### 完了条件
- [ ] 拡大縮小・回転ができる
- [ ] プレビュー→確定→Undo

## E-3: アルファロック（透明部分保護）

### 目的
レイヤーの既存の不透明部分にのみ描画（透明部分は塗らない）。影・ハイライトに必須。

### 設計
レイヤーに `alphaLock: boolean` を追加。ロック中は bake 時に
**描画先の既存 α をマスクとして src に乗算**（既存αが0の所は描かれない）。

### 実装
- `pipeline.ts`: Layer に `alphaLock`、`setLayerAlphaLock(id, bool)`
- bake パス（composite.wgsl の bake）に「dst.a を src に乗算」する alphaLock 版を追加
  - もしくは drawToIsolated の結果に committed.a を乗算してから bake
- UI: レイヤー行にロックトグル（🔒）

### 完了条件
- [ ] ロック中、透明部分には描けない
- [ ] 既存の描画範囲内だけ塗れる
