# PhotonMixer v0.1.2 リリースノート

**リリース日**: 2026-08-02

v0.1.1 から v0.1.2 までの変更内容です。

---

## 新機能

### アプリケーションメニュー

Electronのアプリケーションメニューを追加しました。メニューバーから8割の操作が実行できるようになります。

| メニュー | 項目 | アクセラレーター |
|---|---|---|
| **ファイル** | 新規キャンバス / .pmxを開く / .pmxを保存 / PNGエクスポート / 終了 | Ctrl+N, O, S, Shift+S |
| **編集** | 元に戻す / やり直し / 全選択 / 選択反転 / 選択解除 / キャンバスクリア | Ctrl+Z, Shift+Z, A, Shift+I, D |
| **レイヤー** | 新規レイヤー / 新規フォルダー / 上へ / 下へ / 削除 | Shift+N, Shift+G, Ctrl+], Ctrl+[ |
| **エフェクト** | ぼかし / グロー / シャープ / 露出 / レベル / トーンカーブ / 焼き込み | — |
| **表示** | ズーム±/100% / 回転リセット / 反転 / UI切替 / EV±/リセット / トーンマップ / 表示モード | Ctrl+=, -, 0, Shift+=, Shift+- |
| **ツール** | ブラシ/消しゴム/ぼかし/直線/スポイト/バケツ/選択/移動/変形 | — |
| **ヘルプ** | PhotonMixerについて / GitHub / ドキュメント | — |

メニュー → メインプロセス → IPC → レンダラーのディスパッチャで既存メソッドへ振り分けています。単キーショートカット（B/E/I等）は従来通りレンダラー側のkeydownで処理します。

### macOS対応

ビルドスクリプトをクロスプラットフォーム化し、macOSでビルド・開発・配布ができるようになりました。

- **ビルドスクリプト** — PowerShell依存を除去し、Node.js標準API（`fs.cpSync`）でシェーダー/preloadをコピー
- **Mac配布バイナリ** — `npm run dist:mac` でUniversal dmg（Intel + Apple Silicon）を生成
- **検証スクリプト** — 21スクリプトの `electron.exe` 決め打ちをプラットフォーム分岐ヘルパーに置換

#### macOSでの初回起動手順（署名なしのため）

1. dmgを開いてPhotonMixerをApplicationsへドラッグ
2. FinderでPhotonMixerを**右クリック** → 「開く」
3. 警告ダイアログで「開く」をクリック
4. 以降は通常起動できます

## バグ修正

- **ペン描画中のブラシカーソル追従** — `pointermove` 経由でブラシカーソル円を更新するよう修正。従来は `mousemove` のみで更新していたため、ペン操作中にカーソルが追従しなかった
- **カラーピッカーのポインター追従** — SVボックス・色相バーの操作を `mouse*` → `pointer*` イベントに移行。`setPointerCapture` でドラッグ中の追従を保証
- **キャンバス上の十字カーソル** — 描画系ツール（brush/eraser/blur/line/spoit/bucket）のネイティブカーソルを `crosshair` → `none` に変更。ブラシ円のみ表示し、二重表示を解消

---

## 内部改善

- **LiveStrokeProcessor 抽出** — ペン入力のライブストローク処理を独立モジュール化
- **BlendRenderer uniform バッチング** — uniform バッファをアライメント対応・容量可変に改善
- **StrokeHistory baseRecords 削除** — Undo上限を超えたレコードの保持方式を整理し、JSヒープ使用量を削減
- **検証スクリプト UI セレクタ更新** — UI再設計に追随して `verify-layers.mjs` / `verify-pmx.mjs` のセレクタを更新
