# PhotonMixer v0.1.3 リリースノート

**リリース日**: 2026-09-07

v0.1.2 から v0.1.3 までの変更内容です。

---

## 新機能

### リボンブラシ

スタンプ連打ではなく、中心線リボンのメッシュ描画で一本の線を描く新しいブラシエンジンを追加しました。従来のテクスチャブラシ（`brush`）は「テクスチャブラシ」として残り、新しいリボンブラシ（`ribbon`）がメインブラシになります。

- **滑らかな輪郭** — SDF + `fwidth` でシェーダー側でアンチエイリアス。4x bbox + downsample のパスを通らないため、輪郭がクリア
- **over ブレンドで直接描画** — プレマルチプライドαで isolated へ直接書き込むため、ストロークの重なりで濁らない
- **ショートカット** — `B` がリボンブラシ、`N` がテクスチャブラシに割り当て変更
- **メニュー** — ツールメニューの「ブラシ」がリボンブラシ、「テクスチャブラシ」が従来ブラシ

### テクスチャブラシに「間隔」パラメータを追加

テクスチャブラシのスタンプ間隔（直線比）を 5〜50% の範囲で調整できるようになりました。リボンブラシには間隔概念がないため、このパラメータはテクスチャブラシ選択時のみ表示されます。

### 紐引き補正の速度適応・反転緩み

手ブレ補正の紐引き（Pulled String）モードに2つの適応機能を追加しました。従来の古典動作はテストで保持しています。

- **速度適応** — 描画速度に応じて実効半径を短縮（`effR = radius / (1 + v/adaptiveSpeed)`）。ゆっくり書くときは重く、速く動かすときは軽く追従します
- **反転緩み** — ペンがブラシへ戻る方向（V·S < 0）に動いたとき紐を緩め、角の往復替えしでブラシが置きっぱなしにされる重さを軽減します

## 変更

### 既定値の調整

- **既定ツール** — 起動時のツールを `brush` から `ribbon`（リボンブラシ）に変更
- **既定の補正方式** — `ema` から `pulled-string`（紐引き）に変更
- **既定の混色方式** — `stamp` から `progressive` に変更。起動直後にGPU・CPUどちらの混色も働かない状態を解消します

### ペン圧の平滑化

EMA補正で、筆圧を位置と同じαで平滑化するようになりました。従来は筆圧のみ素通しだったため、低速時に筆圧の急変がそのまま反映されていました。高速時は素通しに近い挙動を維持します。

---

## 内部改善

- **LiveStrokeProcessor の排出点列管理** — 補間窓の再計算で生じる微差（0.1〜0.9pxのスパイク）による二重描画のギザつきを防止。排出済み点列を単調増加・不変で保持し、フラッシュで生じた力窓を切り詰めても再計算で書き換えないようにしました
- **RibbonRenderer の追加** — `src/render/ribbon.ts`（399行）+ `shaders/ribbon.wgsl`（161行）。レンダーパイプラインにリボン描画パスを統合し、スタンプ/リボンをツール切替で切り替えます
- **Undo/Redo のブラシ種別記録** — `StrokeRecord` に `brushKind` を追加し、リボンとスタンプが混在する履歴を正しく再現
- **EngineCtx に spacing 制御を追加** — 補間点間隔をツール・筆径・間隔比から決定。リボンブラシは常に密接補間、テクスチャブラシは直線比
