1 単純移動平均（Moving Average / FIR）

PhotonMixer: 未採用 FIR フィルタ O(1)〜O(N)
直感的理解: 過去 N 個の点の「重心」にブラシを引っ張る。窓からはみ出た古い点は忘れる。
output[i] = (input[i] + input[i-1] + ... + input[i-N+1]) / N
赤=生入力（手ブレ）、緑=移動平均後。窓内 N 点の重心を出力とする。

メリット

  • 実装が最もシンプル
  • 窓サイズ N で直感的に強度調整
  • 安定した平滑化

デメリット

  • 遅延が N/2 サンプル発生
  • 窓内の全点を等価に扱う（最近の点も古い点も同じ重み）
  • 鋭角が丸まる
採用: Krita Basic、LazyNezumi Moving Average

2 指数移動平均（EMA / IIR）

PhotonMixer: 採用済み IIR フィルタ O(1)
直感的理解: 「前の補正結果」と「新しい入力」を α:（1-α）で混ぜる。α が小さいほど古い結果を引きずる＝強い平滑化。過去すべての点が指数的に（遠ざかるほど薄れて）効く。
output[i] = α × input[i] + (1 - α) × output[i-1]
α が小さい → 強い補正（遅延大）　／　α が大きい → 補正なし（遅延小）
赤=生入力、緑=EMA出力（α=0.3）。各ステップで「前の出力」と「新入力」を混合。

メリット

  • O(1) で計算量最小（過去全履歴不要）
  • α 一つで強度連続調整
  • 直近の点を重視するので移動平均より遅延が少ない
  • 無限の過去を指数減衰で考慮（自然な追従）

デメリット

  • 設定によっては遅延が目立つ
  • 急な方向転換に弱い（慣性でオーバーシュート）
  • α が大きすぎると補正が効かない
採用: PhotonMixer、LazyNezumi EMA

3 ガウシアン重み付き平均（Weighted Gaussian）

PhotonMixer: 未採用 FIR フィルタ O(N)
直感的理解: 移動平均の「窓内を平等に」を「中央に近いほど重く、遠いほど軽く」に変えた版。釣鐘型の重み付けで、より自然な平滑化ができる。
weight[j] = exp( -(j - center)² / (2σ²) )
output[i] = Σ ( weight[j] × input[j] ) / Σ weight[j]
上: 釣鐘型の重み分布。下: 赤=生入力、緑=ガウシアン平滑化後。

メリット

  • 移動平均より自然な平滑化
  • 直近の点を重視しつつ遠い点も考慮
  • 角が丸まりすぎない

デメリット

  • O(N) でサンプル履歴が必要
  • σ のチューニングが難しい
  • 遅延は発生する
採用: Krita Weighted Smoothing（sigetch アルゴリズム改良版）

4 Pulled String（紐引き方式）

PhotonMixer: 未採用 Dead Zone O(1)
直感的理解: ブラシとペン先を「一定の長さの紐」で繋ぐ。ペン先が紐の半径内にいる間はブラシは動かない。紐が張ったときだけブラシが引っ張られて動く。止まると追いつく。
紐の半径=平滑化の強さ。半径内の小さな動きは無視され、鋭角が作れる。

メリット

  • 鋭い角を残せる（他の手法は角が丸まる）
  • 直感的な動作（紐の長さ＝半径）
  • 低速の精密作業に最適
  • 停止時に自然に追従

デメリット

  • 高速な曲線描きには不向き
  • 半径内で動かないと線が途切れる
  • 動的な線には硬く感じる
採用: SAI S-1〜S-7（推測）、Photoshop Pulled String、LazyNezumi Pulled String、Krita Stabilizer

5 Inertia（慣性・物理シミュレーション）

PhotonMixer: 未採用 物理シミュ O(1)
直感的理解: ブラシに「質量」を持たせ、ペン先との距離を「力」として働かせる。ブラシは慣性で動き続け、drag（抗力）で減速する。弾むような自然な線になる。
force = (penPos - brushPos) × springK
acceleration = force / mass - velocity × drag
velocity += acceleration × dt
brushPos += velocity × dt
ペン先とブラシをばねで繋ぎ、ブラシに質量と抗力を与える。移動平均同等の平滑化をより少ない遅延で実現。

メリット

  • 移動平均同等の平滑化をより少ない遅延で実現
  • 流れるような自然な線
  • 筆圧を速度から自動生成（テーパリング）
  • 書道・カリグラフィーに最適

デメリット

  • パラメータが多い（mass, springK, drag）
  • チューニングが難しい
  • 停止時に弾むことがある
採用: LazyNezumi Inertia（2023年追加）、CloverPaint（慣性運動タイプ）

6 速度適応α（Speed-Adaptive Smoothing）

PhotonMixer: 採用済み EMA拡張 O(1)
直感的理解: EMA の α を固定値ではなく、ペンの速度に応じて動的に変える。ゆっくり描いている時は α を小さく（強い補正）、速く描いている時は α を大きく（補正を弱めて遅延を隠す）。
α = clamp(speed / threshold, minAlpha, maxAlpha)
低速 → α が小さい → 強い平滑化（ブレを消す）
高速 → α が大きい → 補正を弱める（遅延を隠す）
上: α は速度に対して線形に立ち上がる。下: 低速部は強く平滑化、高速部は生入力に近い。

メリット

  • 「遅い時はブレを消す・速い時は遅延を隠す」を自動切替
  • ユーザーが状況に応じて補正を切り替える必要がない
  • EMA の上に乗せるだけ（実装が簡単）

デメリット

  • threshold のチューニングが必要
  • 中速域で補正が中途半端になることがある
  • マウス入力では速度が常に高めになりがち
採用: PhotonMixer、クリスタ（速度による手ブレ補正）、Krita Stabilizer（Max/Min Speed）、LazyNezumi Speed Smooth

7 予測ストローク（Stroke Prediction）

PhotonMixer: 実装済み（無効化中） 外挿予測 O(1)
直感的理解: 補正による遅延を隠すため、「ペンは次はこのへんに来るはず」と予測して先の線を仮描画する。実点が到着したら予測部分を差し替える。クリスタの「ストロークプレビュー」と同じ発想。
velocity = (lastPoint - prevPoint) / dt
acceleration = (velocity - prevVelocity) / dt
predictedPoint = lastPoint + velocity×dt + 0.5×acceleration×dt²
最後の実点から速度・加速度で予測点を外挿し、先の線を仮描画して遅延を隠す。

メリット

  • 補正による遅延を体感上隠せる
  • 高速描画での追従性が改善
  • クリスタも採用（ストロークプレビュー）

デメリット

  • 予測が外れると線が揺らぐ（シャギー）
  • 「先端だけ別描画して差し替え」方式が必要
  • 「全体再描画」方式とは相性が悪い
採用: PhotonMixer（実装済・無効化中）、クリスタ（ストロークプレビュー）

8 後補正（Post-Correction / 事後補正）

PhotonMixer: 未採用 曲線フィッティング O(N)〜O(N²)
直感的理解: リアルタイム補正とは全く違うアプローチ。ストロークを描き終わった後（ペンアップ時）に、線全体を見て「一番近い滑らかな曲線」に再構成する。「描いた後に線がシュッと整う」やつ。
ペンアップ時に線全体を再平滑化。リアルタイム補正の弱点（ラグ・揺らぎ）を補完。

メリット

  • 線全体を見られるので最も精度が高い
  • リアルタイム補正の遅延・揺らぎを気にしなくてよい
  • 「描いた後にシュッと整う」体験が気持ちいい
  • 角を保持しつつ滑らかにできる

デメリット

  • リアルタイムではない（確定後の補正）
  • 計算コストが高い（特に曲線フィッティング）
  • 実装が複雑
  • 細かい描き込みには不向き
採用: クリスタ（後補正）、ibisPaint（事後補正）、SAI（ペン入れレイヤーのベジェ変換）

9 筆圧平滑化（Pressure Smoothing）

PhotonMixer: 未採用 EMA / 移動平均 O(1)
直感的理解: 位置の平滑化と同じことを筆圧にも適用する。安価なタブレットでは筆圧センサーがノイズを含むことが多く、太さがブレるのを防ぐ。
筆圧センサーのノイズをEMA等で平滑化。線の太さが安定する。

メリット

  • 安価なタブレットで効果絶大
  • 実装が簡単（位置のEMAと同じロジック）
  • 線の太さが安定
  • オン/オフ切り替え可能

デメリット

  • 筆圧の素早い変化が鈍る
  • テーパリング（先細り）が弱くなる
  • 高級タブレットでは不要なことが多い
採用: Krita（Smooth Pressure オプション）、LazyNezumi（4つの筆圧モード）
